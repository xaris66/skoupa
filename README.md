# Σκούπα Κινητού

Εφαρμογή καθαρισμού κινητού — web εφαρμογή (HTML) που γίνεται Android APK.

## Αρχεία
- `index.html` — η εφαρμογή
- `icon.svg`, `manifest.webmanifest` — εικονίδιο και ρυθμίσεις PWA
- `.github/workflows/build-apk.yml` — το workflow «Φτιάξε APK»

## Πώς βγαίνει το APK
1. Καρτέλα **Actions** → **Φτιάξε APK** → **Run workflow**
   (τρέχει και αυτόματα σε κάθε αλλαγή στο `index.html`).
2. Όταν τελειώσει, το APK είναι εδώ:
   **https://github.com/xaris66/skoupa/releases/latest/download/Skoupa.apk**
3. Στο κινητό: άνοιξε το αρχείο και επίτρεψε «Εγκατάσταση από άγνωστες πηγές».
