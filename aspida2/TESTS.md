# Ασπίδα 2 — Πίνακας 51 δοκιμών αποδοχής

**Πώς διαβάζεται:** κάθε δοκιμή έχει δύο στήλες αποτελέσματος.
- **Πυρήνας**: ο «εγκέφαλος» (ανάλυση συνδέσμων και αρχείων, καραντίνα), που τρέχει πραγματικά με προσομοιωμένο δίκτυο. Τα αναλυτικά αποτελέσματα είναι στο `core-test-results.txt`, που ξαναβγαίνει σε κάθε χτίσιμο στο GitHub Actions.
- **Κινητό**: εκτέλεση στο Samsung Galaxy S26 Ultra. Είναι **NOT RUN** μέχρι να γίνει η δοκιμή στο κινητό.

Καμία δοκιμή δεν μετράει ως PASS χωρίς εκτέλεση. Οι απαντήσεις της Google Safe Browsing και του URLhaus στις δοκιμές του πυρήνα είναι **προσομοιωμένες**, με την ακριβή μορφή της τεκμηρίωσης v5. Ο πραγματικός έλεγχος με το κλειδί σου γίνεται στο κινητό.

Εκτός από τον πυρήνα, ο κώδικας της εφαρμογής (Android) **μεταγλωττίστηκε χωρίς σφάλματα** με τη βιβλιοθήκη Android API 34. Το πλήρες χτίσιμο APK με Gradle γίνεται στο GitHub Actions.

**Σύνοψη:** 38 από τις 51 έχουν περάσει στον πυρήνα ή σε στατικό/μερικό έλεγχο (3 με προσομοιωμένη απάντηση υπηρεσίας, 1 μόνο ως μεταγλώττιση). Μαζί με τις επιπλέον δοκιμές (T07b, T17b, T28b, T32b, T34b, T37b, T45b/c, PSL, gov.gr, IDN, javascript:, ιδιωτικό δίκτυο, ZIP slip, JSON), ο πυρήνας περνάει **50/50**. Και οι **51** είναι NOT RUN στο κινητό μέχρι να τρέξουν στο S26 Ultra.

Οι 51 δοκιμές είναι η ελάχιστη λίστα αποδοχής. Δεν εγγυώνται πλήρη ασφάλεια.
